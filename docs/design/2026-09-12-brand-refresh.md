# Zurtex mark and photography refresh

The user requested a new brand logo, a replacement for the implausible airport photograph and a more minimal loading interface. All existing verification-process wording must remain intact. This is an explicit update to the logo and hero assets inside the established white, aqua, teal and Afacad system, not a replacement of the site's visual identity.

## Direction contract

**THESIS:** A recognisable pet-travel mark and a quiet, legible journey in progress.

**OWN-WORLD:** An original filled paw with a Z-shaped central pad, paired with the existing Afacad wordmark. Deep teal, clear negative space and no enclosing badge. Natural photographic texture replaces the staged carrier scene.

**STORY:** The traveller recognises Zurtex, sees a believable relationship between pet and owner, and can follow the actual source checks.

**FIRST VIEWPORT:** Keep the familiar landing composition, with the new wordmark and a closer airport portrait. The loading page uses a small plane arriving over a geometric folded map, a restrained heading and clearly visible current activity and progress.

**FORM:** Directly shaped extension under the user's specified brief; code-led. The plane was selected over a second paw because it communicates movement while the brand mark already identifies the pet. No concept seed is required for this narrow revision.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction: the plane advances toward the map's destination only when real source-check stages finish. No timer manufactures progress.

## Asset production

The mark is original editable SVG geometry. The wordmark uses the existing Afacad family; distribution SVGs use outlined lettering so the logo stays consistent without a font dependency. The photograph is a new built-in ImageGen output. Its exact prompt, origin and visual checks are recorded in `2026-09-12-brand-photo-prompt.md`. It is a generated brand image, not a real customer photograph.
